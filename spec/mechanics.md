# ゲームメカニクスおよびシステム詳細設計書

本ドキュメントは、地底の探索において、自動生成・マッピングの法則、固い土の破砕耐久値制御、デバフ時間短縮による駆け引きの変化、および敵の撃破とリスポーン制御のアルゴリズムを厳密に定義した設計書です。

---

## 1. グリッド倍加＆土の増量生成システム

元のマップ（11x16）から、広大な戦闘フィールド（22x32）へ2倍スケールアップしつつ、さらに「土（DIRT）を増量し、採掘可能領域を高密度化」する生成メカニズム。

### A. スケールアップ変換と土の増量密度 (Soil Density Boost)
単に2倍に広げるだけでなく、元の空洞部分に対して「最大で 15〜25% の追加の崩落土（通常の土および固い土）」をランダムに流し込み、同志が削り甲斐のあるボリューム（土だらけのワクワク地中）をプログラムレベルで自動増量します。
* **変換マッピング**:
  * 元の壁（WALL: `#`）および空間（EMPTY: ` `）を、2x2セルに展開するプロセスで、一定の空き空間だった箇所を難易度別確率で「通常の土（HP 1）」または「固い岩盤土（HP 3）」に補完・充填します。
  * これにより、プレイヤー同志が土のトンネルを自由にくり抜き、敵から身を隠しながら独自の拠点やおとり迷路を築くことが可能になります。

## 2. 固い土 (HP 5) の多重耐久値削り込みアルゴリズム

固い土は、単独の1ビットの生存フラグではなく、**内部に 0〜5 の耐久値（Health Point）カウンタ**を持たせることで状態管理を実装します。

```
[ドリル入力/進行移動] -> 対象が「固い土 (HP 5)」か判定
     |
     +--> HPを-1減算 (残り 4) 
     |    * 「キィーン」という大火花金属エフェクトの発生
     |    * 土に一対の「ヒビ割れ亀裂」を描画
     |
     [プレイヤーは次のマスへ進めず、踏みとどまる (進路のブロック)]
     |
     +--> 2〜5回目のヒットで HPが0に到達
          * ブロック全体の破壊パーティクル飛散
          * 対象のセル属性を「EMPTY」へと書き換え
          * 同志が初めてそのマスへと踏み込める状態(移動成功)に移行
```

## 3. 超短縮おとり罠＆直接ドリル攻撃のアルゴリズム

「足長デバフ」を「超短デバフ」へと仕様調整し、能動的ハント（直接撃破）を誘発する状態遷移マシン。

* **おとり罠のタイムアウト (T) 制御**:
  * マシンのタイマー： $Interval = SPEED\_TICK$ 周期（430ms）。
  * 敵が罠への侵入フラグを立てた瞬間： $TrappedRemaining = 6$ カウント（約2.5秒）に設定。
  * この値は 1 周期（430ms）ごとに $TrappedRemaining$ が 1 ずつ自動減算されます。
  * **自動充填による圧縮撃破 (Refill Crush)**:
    * デバフ期間中に同志がトドメを刺せなかった場合でも、カウントが 0 になった瞬間に穴は土で埋まります。その際にまだ敵が穴にいるならば、土砂崩落による圧死撃破（Crush）が呼び出され、敵はデブリとなって消え去りハイスコアが加算されます。
  * **隣接ドリル攻撃 (Drill Strike) の判定**:
    * $TrappedRemaining > 0$ である敵に対し、隣接セル（マンハッタン距離 = 1）にいる同志が、敵のいる方向へドリルアタックをかけた場合、即時ハント関数 `CrushEnemy(enemy.id)` が発火し、その場で敵が吹き飛び爆発。同志は +350 PTS を即時獲得します。

## 4. 敵の撃破後リスポーン（復活）冷却アルゴリズム

倒された敵は、ゲームバランスの破綻（無敵化）を防ぐため、一定の「待機（コールドタイム）」を経て戦列に戻ります。

1. **撃破フラグの即時セット**:
   * 対象の敵オブジェクトのメンバ `isDead` を `true` に変更し、スプライトを非表示、アラウンドBFS追跡対象から一時除外。
2. **リスポーンタイマーのシークエンス**:
   * 撃破されてから **8ゲームクロック（約3.4秒）** のクールダウン時間。
3. **初期座標への自動テレボート＆リセット**:
   * タイマー満了後、敵をマップ独自の `enemyStarts` の位置（それぞれが初期配置されていた座標）に移動。
   * `isDead = false`, `trappedRemaining = 0` の状態に戻し、カモフラージュタイプの敵は再び「睡眠（擬態）」状態をセットしてアクティブに復帰します。
