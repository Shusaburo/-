# ゲーム概要とコンセプト設計書

本ドキュメントは、地表から地下深くへ潜る2Dアクションパズルの基本コンセプト、安全ルール、およびエキサイティングな戦闘仕様を定義したマスター仕様書です。

## 1. ゲームコンセプト
* **ゲームタイトル例**: 地底採掘ハント（Underground Excavation Hunt）
* **ジャンル**: 2D能動型穴掘りアクションパズル
* **ターゲットプラットフォーム**: PC / モバイル両対応 Webブラウザ
* **コアとなるゲームループ**:
  1. プレイヤーである「**同志**」は縦横に広がる地中マップを自由に移動・採掘しながら、散らばっている「結晶（GEM）」を集める。
  2. 追いかけてくる多様な特性を持つ「敵」を、自ら掘る「おとり罠（トランプ）」や「ポータブル高熱ドリル」での直接攻撃で粉砕・撃退する。
  3. ステージ上のすべての結晶を回収すると、昇降機である「脱出ポータル（GOAL）」が起動し、そこへ到達することでステージクリア。
  4. 新たな「固い土」を力強く削りながら、パワーアップアイテムを使ってさらに有利に、爽快に地中を支配していく。

---

## 2. プレイヤー「同志」無敵＆アグレッシブ戦闘仕様

本作は、敵とぶつかってすぐ死ぬようなストレスフルなレトロゲームとは一線を画す、**「敵に当たっても死なないが、自分からどんどん敵をハンティングして高得点を極める」という、超爽快で主体的（アグレッシブ）な自由度の高いゲームデザイン**を採用しています。

* **接触時の処理**: 
   * 通常状態で敵に接触してもすり抜けることができ、ペナルティでリトライになることはありません。
   * 接触時には「⚡ CONTACT (★SAFE★)」のエフェクト粒子が表示され、ゲームの快適な進行を損なわないようになっています。
* **同志からの能動的ハント（撃破）システム**:
   * 同志は、罠にハメた敵に近づいてドリルを突き刺す（ドリル・エクスプロージョン）、持続アイテム「超ハイパードリル [T]」で敵ごと掘り進み粉砕する、といった攻撃手段ですべての敵を能動的に撃破できます。
   * 撃破された敵は、一定時間のディレイ後に敵の初期開始ポイントから安全にリスポーン（復活）します。

## 3. キャラクター・エンティティ定義
プレイヤー「同志」と、ゆっくりながら的確に同志を阻む個性的な敵たちの仕様。

### A. プレイヤー「同志」 (Comrade)
* **自動採掘 (Auto-Drill)**: 進行方向に土（通常の土は1発、固い土は5発）がある状態で進むだけで自動的に削り倒して突き進む。
* **おとり罠掘り (Trap-Dig)**: 進行方向の斜め下または左右 of 足元に、一時的な深穴を瞬時に掘る（足止めデバフ時間は1.5秒と非常に短く、罠にかかったら自らすぐトドメを刺さないとすぐに逃げられる！）。

### B. 敵 (Enemies)
基本行動周期をシャープでスリリングな **超高速テンポ（270ms）** へと大増速！同志が「おとり罠」を設定するスピードや、一瞬の退路確保の判断力がリアルタイムに試されます。地底空間の洗練されたパズル性を維持するため、**1ステージあたりの最大出現総数は3体まで**に制限されていますが、その狂暴さは一新されています。
* **CHASER (チェイサー/赤)**: 最短経路を割り出し、270msの爆速で執念深くストーキングする。
* **WANDERER (ワンダラー/黄)**: 通常は2 ticks（540ms）に1歩だが、直視内に入ると毎tick（270ms）の最高速ダッシュで同志へ突進。
* **GHOST (ゴースト/紫)**: DIRTブロックを自由にすり抜け、従来のゆっくりペースから「2 ticksに1回＋25%の確率で毎ターン」の予測不能な浮遊スピードに引き上げられ、同志を絶望の淵へ追い詰める。
* **PATROLLER (パトローラー/青)**: 一定コースを巡回。休みなく毎tick稼働するプロの警備員へと進化し、わずかな侵入の隙も与えない。
* **AMBUSHER (アンブッシャー/橙)**: 泥土を装い休眠。接近（4マス以内）されると牙を剥き、毎tickの猛スピードで突撃を開始。

## 4. 特殊機能・地形・アイテムの明解グラフィック

地下鉱山で重要な情報を同志が見失わないようにするために、各オブジェクトは視認性を格段に高めた高コントラストなグラフィック、パルス（明滅）、および陽炎（熱波）のアラートエフェクトを標準採用しています。詳細は別紙 `spec/items_and_terrain.md` に定義されています。
* **固い土**: 亀裂が入る白ラインが徐々に増え、爆裂火花が散る。
* **結晶 (GEM)**: シアンブルーのまばゆい光源を持ち、周囲を淡く照らし高速明滅・回転。
* **脱出ポータル (GOAL)**: 全結晶回収で巨大な「ブラックホール（うず巻く空間の裂け目）」としてダイナミックに出現。
